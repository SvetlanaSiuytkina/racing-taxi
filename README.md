# Гоночное такси 🏎️

Одностраничное приложение (SPA) с навигационным меню на React + React Router + Vite

## Что внутри

- 4 страницы: **Главная**, **Дрифт-такси**, **Time Attack**, **Forza Karting**
- Верхнее меню на `NavLink` с подсветкой активного пункта
- Клиентский роутинг без перезагрузки страницы
- Страница 404 для несуществующих маршрутов

## Стек

- React
- React Router
- Vite
